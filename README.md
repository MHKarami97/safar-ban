# سفربان (SafarBan)

اپلیکیشنی برای ثبت لوکیشن‌های سفر (استان به استان، کشور به کشور، شهر به شهر) و برنامه‌ریزی کامل سفر با تاریخ شمسی. ساخته‌شده با Vue 3، Vite و Pinia؛ تمام داده‌ها آفلاین در `localStorage` مرورگر ذخیره می‌شوند.

## نصب و اجرا

```bash
npm install
npm run dev
```

برای build نهایی (شامل Service Worker و Manifest):

```bash
npm run build
npm run preview
```

## قابلیت‌های اصلی

### لوکیشن‌های سفر
- ۳۲ استان ایران به‌صورت پیش‌فرض فعال و قابل نمایش در صفحه اول؛ هر استان قابل غیرفعال‌سازی است.
- لیست کشورها به‌صورت پیش‌فرض غیرفعال؛ فقط با انتخاب کاربر در صفحه «مدیریت استان‌ها و کشورها» فعال می‌شود.
- ساختار درختی استان/کشور ← شهر ← لوکیشن (مثل استان فارس ← شیراز ← آرامگاه حافظ).
- امکان انتخاب چند لوکیشن با هم به‌عنوان «رفته‌شده» و ثبت یک جزئیات مشترک: تاریخ (شمسی)، هزینه کلی، تعداد روز، کیلومتر، توضیحات.
- لوکیشن‌های رفته‌شده در لیست جدایی در پایین همان استان نشان داده می‌شوند و قابل ویرایش/بازگردانی هستند.

### برنامه‌ریزی سفر
- ساخت برنامه سفر با عنوان، توضیحات، تاریخ شروع شمسی (با انتخابگر تاریخ اختصاصی)، تعداد روز و محاسبه خودکار تاریخ پایان.
- پیش‌بینی آب‌وهوای هفت روز آینده مقصد (Open-Meteo، بدون نیاز به کلید API).
- انتخاب وسیله نقلیه، هم‌سفرها، مدارک لازم و تجهیزات سفر از لیست‌های قابل‌استفاده‌ی مجدد، با امکان افزودن مورد جدید.
- ثبت نکات فرهنگی و قوانین محلی مقصد.
- صفحه جدای چیدن مقاصد روزانه: هر مقصد با ساعت شروع و مدت‌زمان، محاسبه خودکار ساعت پایان، و هشدار همپوشانی زمانی بین مقصدها؛ همچنین اقامتگاه هر روز (نام، آدرس، شماره تماس).
- صفحه راهنمای مجزا برای چیدن برنامه سفر.
- ثبت رویداد روزانه در طول سفر (مقاصد رفته‌شده/نرفته، هزینه روز، وسیله، وضعیت لوکیشن‌ها و اقامتگاه، توضیحات) با امکان ویرایش کامل.
- وضعیت سفر: در حال برنامه‌ریزی، پیش رو، در حال انجام، پایان یافته — سفرهای پایان‌یافته در بخش جدا در پایین لیست سفرها نمایش داده می‌شوند.
- فیلتر وضعیت و جستجو در لیست سفرها.
- خروجی پرینت شیک از هر برنامه سفر (بدون نیاز به کتابخانه PDF خارجی).

### پشتیبان‌گیری کامل
- دکمه «خروجی کامل» در صفحه اول، تمام داده‌های اپ (لوکیشن‌ها، استان‌ها/کشورها، سفرها، رویدادها، لیست‌های شخصی) را در یک فایل JSON ذخیره می‌کند.
- دکمه «ورودی کامل» همان فایل را به‌طور کامل بازیابی می‌کند.

## استک فنی

| لایه | ابزار |
|---|---|
| Framework | Vue 3 + Composition API (`<script setup>`) |
| Build Tool | Vite |
| State Management | Pinia |
| Styling | Tailwind CSS (Mobile-First, RTL) |
| PWA | vite-plugin-pwa |
| Persistence | localStorage از طریق Repository Pattern |
| تاریخ شمسی | الگوریتم تبدیل جلالی/میلادی داخلی (بدون وابستگی خارجی) |
| آب‌وهوا | Open-Meteo (رایگان، بدون کلید API) |

## معماری پروژه

```
src/
├── models/
│   ├── region/        # Location, City, Region, VisitRecord
│   └── trip/           # TripDestination, Accommodation, TripEvent, TripPlan, CatalogItem
├── services/
│   ├── region/          # RegionFactory, RegionRepository
│   ├── trip/             # TripFactory, TripRepository, CatalogRepository, WeatherService, TripPrintService
│   ├── StorageService.js
│   └── BackupService.js
├── stores/               # regionStore, tripStore, catalogStore, uiStore (Pinia)
├── composables/
├── components/
├── views/
├── data/                 # provinces.js, countries.js
├── utils/                # jalali.js, id.js
└── router/
```

## الگوهای طراحی به‌کاررفته

- **Repository Pattern:** هر دامنه (region/trip/catalog) لایه‌ی مجزای repository دارد که ارتباط با `localStorage` را از UI جدا می‌کند.
- **Factory Pattern:** `RegionFactory` و `TripFactory` مسئول ساخت aggregate rootها از روی تعاریف خام یا ورودی کاربر هستند.
- **Aggregate Root:** `Region` و `TripPlan` تمام قوانین دامنه (محاسبه پیشرفت، همپوشانی زمانی، مدیریت visit record) را در خود نگه می‌دارند.
- **Facade Pattern:** `BackupService` خروجی/ورودی کامل اپ را بدون آگاهی از جزئیات هر ریپازیتوری فراهم می‌کند.
- **Observer/Reactive Pattern:** استورهای Pinia منبع واحد حقیقت هستند و تغییرات را reactive پخش می‌کنند.

## PWA

فایل `vite.config.js` شامل تنظیمات کامل `manifest` (نام سفربان، آیکون SVG، `theme_color`، `dir: rtl`) و استراتژی `generateSW` است.
